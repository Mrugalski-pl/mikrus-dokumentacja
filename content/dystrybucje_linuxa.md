# Dostępne dystrybucje Linuxa

Na Mikrusie dostępne są następujące dystrybucje Linuxa:

- Ubuntu 26.04 - Resolute Raccoon
- Ubuntu 24.04 - Noble Numbat
- Ubuntu 22.04 - Jammy Jellyfish
- Debian 13 (2025.09)
- Debian 12.1 (2023.08)
- Debian 11
- ArchLinux (2026.09)
- Rocky Linux 9.1
- Rocky Linux 8
- Alma Linux 8
- Alma Linux 9.3
- Alpine 3.16
- Centos 8
- Oracle Linux 8
- Nightscout (dla cukrzyków) ([Więcej informacji](https://typefully.com/uwteam/serwery-w-sluzbie-dzieciom-7L4gkrZ))

> 💡 Na Mikrusie 1.0 niedostępne są: Ubuntu 26.04, ArchLinux oraz Nightscout.

Domyślnie nowy serwer otrzymuje system **Ubuntu**. System możesz zmienić w dowolnym momencie, wykonując reinstalację w panelu (menu **Mój VPS** → **[Reinstalacja](https://mikr.us/panel/?a=reinstall)**).

> 🔥 Reinstalacja **usuwa wszystkie dane** z Twojego serwera. Zanim ją wykonasz, zrób backup (np. na [Strych](../strych_backupy)).

Po reinstalacji zmieni się odcisk palca serwera SSH, więc Twój klient SSH może zgłosić [błąd "Remote Host Identification has changed!"](../blad_ssh_remote_host_identification_has_changed). To normalne.

Serwery darmowe [FROG](../frog) działają wyłącznie na systemie Alpine Linux.
